This page simulates any of your websites. The assistant lives in the bottom-right corner — click the button to open it. Answers stream word-by-word over the same /api/ai/chat/stream endpoint the Angular library consumes.

Open the ⚙ panel inside the chat to unlock Settings. The default setup runs fully self-hosted (local model sidecar — nothing sent to an external provider); vendor API keys are optional extras (multiple keys, automatic fallback). You can also upload your own documents (PDF / DOCX / Markdown) and switch voice input & output on. Demo only: the sample password is pixous — set your own AiSuite:Settings:Password before any real deployment.

Supported languages

Add keys for any vendors you like — several at once (OpenAI, Anthropic, Gemini, DeepSeek, Groq, Mistral, OpenRouter, Ollama, or any custom OpenAI-compatible endpoint). The assistant tries them in priority order; when a key is definitively rejected (invalid/denied, or rate-limited per your quota-fallback setting) the next key is tried. A timeout, 5xx or network failure is never silently retried or failed over — the call may already have been processed and billed — unless you explicitly opt in. Keys are stored server-side and shown masked only (never returned to the browser); a key is sent only to its own configured provider when a call is made.
